# Run a project audit with ChatGPT or Codex

Copy the prompt below and provide this repository or the checklist as a reference.

> Audit my project using the PANTIK UI/UX Knowledge Base.
>
> - Project — [website URL, Figma link, repository, build, or screenshots]
> - Platform — [web, native app, or Figma]
> - Primary journey — [user goal and starting point]
> - Version, languages, and target devices — [if known]
>
> Apply the common checks and the checks for the relevant platform from Audit-Checklist.csv. Run the main journey and applicable loading, empty, error, and success states. On a working build, test the viewport widths and input methods available to you. When code confirms a cause, provide the file and line.
>
> For a design file or screenshots, assess visible details and mark build-dependent behavior as Not tested. Record the reason for any blocked check and continue with checks that remain possible.
>
> For each confirmed issue, report the checklist ID, priority, screen, reproduction steps, actual and expected outcomes, evidence, suggested fix, and acceptance check. List hypotheses and untested checks separately. Use 07-report/audit-report.md and identify the three fixes to tackle first.
>
> Change project files or create GitHub issues only if I ask separately.
