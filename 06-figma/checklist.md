# Figma and developer handoff

[Start here](../README.md) · [Source register](../08-sources/sources.md)

## FIG-01 — Components and variants

- **Applies to** — Figma
- **How to test** — Check whether repeated elements use component instances and differences are expressed as variants or properties.
- **Suggested fix** — Connect instances to main components and name variants by purpose.
- **Sources** — [FG](https://help.figma.com/)

## FIG-02 — Variables and styles

- **Applies to** — Figma
- **How to test** — Compare repeated color, type, and spacing values across frames.
- **Suggested fix** — Apply consistent styles and variables. Check the relevant modes.
- **Sources** — [FG](https://help.figma.com/)

## FIG-03 — Auto Layout

- **Applies to** — Figma
- **How to test** — Resize frames and replace short labels with longer copy. Check wrapping, buttons, and nested layouts.
- **Suggested fix** — Configure Hug, Fill, and sizing constraints to match intent.
- **Sources** — [FG](https://help.figma.com/)

## FIG-04 — Prototype journey

- **Applies to** — Figma
- **How to test** — Run the main path, Back, and an error-recovery branch.
- **Suggested fix** — Connect the relevant frames and annotate behavior for implementation.
- **Sources** — [FG](https://help.figma.com/)

## FIG-05 — Accessibility annotations

- **Applies to** — Figma
- **How to test** — Check that intended accessible names, focus order, and error messages are documented.
- **Suggested fix** — Annotate key components and verify actual behavior on the build.
- **Sources** — [WAI](https://www.w3.org/WAI/test-evaluate/preliminary/)

## FIG-06 — Developer handoff

- **Applies to** — Figma
- **How to test** — Check the design version, states, responsive rules, source assets, and interaction details.
- **Suggested fix** — Record expected behavior and compare the implementation with the agreed design.
- **Sources** — [FG](https://help.figma.com/)

## FIG-07 — Edge cases

- **Applies to** — Figma
- **How to test** — Try a long heading, a long translation, an empty list, and a large number of cards.
- **Suggested fix** — Save representative frames and communicate the expected behavior.
- **Sources** — [FG](https://help.figma.com/)
